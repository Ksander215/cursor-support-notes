# 72h Outbound Sprint (Express Audit)

Цель: получить первые оплаты быстрее всего через услуги (`/audit`) в белом режиме.

## Sprint rhythm

- `H0-H4`: подготовка ICP, офферов, списка лидов.
- `H4-H24`: 20 персонализированных касаний.
- `H24-H48`: follow-up + 4 звонка.
- `H48-H72`: закрытие сделок, апсейл в digital продукты.

## Offer stack

1. `Express API Audit` — `3000 RUB`, SLA 2 часа.
2. `Audit + Fix consult` — `5000 RUB`, SLA 24 часа.
3. `Bundle` (audit + PDF + templates) — `5900 RUB`.

## Daily target

- 20 новых контактов в сутки.
- 6 квалифицированных диалогов.
- 2 коммерческих предложения.
- 1 оплаченная сделка в день.

## Message scripts

### First contact (Telegram/DM)

```text
Привет! Увидел, что у вас API-проект на этапе релиза.
Делаю экспресс-аудит за 2 часа: проверка критичных уязвимостей + короткий отчет с фиксациями.
Стоимость: 3000 ₽.
Если актуально, скину 1-страничный scope и стартанем сегодня.
Подробнее: https://sec-scanner.pro/audit
```

### Follow-up D+1

```text
Коротко напоминаю про экспресс-аудит.
Если у вас релиз/сдача в ближайшие дни, могу взять в слот сегодня.
Результат: список рисков + что исправить в первую очередь.
```

### Follow-up D+2 (with urgency)

```text
Закрываю набор на эту неделю, остался 1 слот.
Если нужна проверка до релиза, могу подтвердить время и сразу отправить scope работ.
```

## Qualification rules

- `Hot`: релиз <= 7 дней, есть бюджет, есть технический контакт.
- `Warm`: интерес есть, но срок > 7 дней.
- `Cold`: нет бюджета/интереса сейчас.

## Proposal skeleton

```text
Объем:
- Проверка API по основным критическим классам рисков
- Краткий отчет (PDF/Markdown)
- 30-минутный разбор результатов

Стоимость: <3000|5000> ₽
Срок: <2 часа|24 часа>
Старт: <дата/время>
```

## Execution tracking

- Заполнять `agent_outputs/OUTBOUND_72H_TRACKER.csv` после каждого касания.
- Перевод в `Call/Proposal` только при подтверждении боли/срока.
- После оплаты сразу создавать карточку `Delivery/Follow-up` в Vibe Kanban.

## End-of-sprint exit

- Не менее 60 касаний.
- Не менее 12 диалогов.
- Не менее 4 оплат.
