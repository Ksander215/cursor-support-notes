## После отправки

Обнови файл `agent_outputs/OUTBOUND_72H_TRACKER.csv`: найди строку по **`contact_name`** (например `dev_2`).

- **`notes`:** допиши факт: исходящее отправлено (дата/время); когда ответил клиент — дата/время ответа и кратко суть.
- **`next_step`:** после ответа и договорённости о звонке/КП можно поставить `call_or_proposal` (или ваш следующий код шага).
- **`next_step_at`:** дата следующего действия (звонок, дедлайн КП, напоминание).
- **`status`:** при необходимости обнови (`warm`, `hot`, `contacted` — в таблице используются эти значения; отдельного `qualified` в CSV нет).

Поля `replied` / `replied_at` в этом CSV **не используются** — фиксируй ответ через **`notes`** и шаги выше.
