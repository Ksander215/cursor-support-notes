# SOP: Manual Payment (No IP mode)

Режим до подключения ИП + YooKassa.

## Стандартный процесс

1. Лид подтверждает пакет (`3000/5000/5900`) в переписке.
2. Статус в трекере: `payment_pending`.
3. Отправляете реквизиты/СБП и дедлайн слота.
4. Получаете подтверждение и сверяете поступление вручную.
5. Статус: `won`.
6. Запускаете delivery и follow-up.

## Шаблон сообщения на оплату

```text
Фиксирую договорённость:
- Пакет: [Express/Standard/Bundle]
- Стоимость: [3000/5000/5900] ₽
- Срок: [2 часа/24 часа]

Для старта нужна оплата.
После подтверждения сразу беру в работу.
```

## Шаблон дожима

```text
Держу для вас слот до [время].
Если подтверждаете оплату до этого времени — стартуем сегодня.
Если нет, переношу слот следующему в очереди.
```

## Анти-риски

- Без оплаты — без старта работ.
- Для срочных кейсов фиксируйте дедлайн в сообщении.
- Не давать скидку до первого закрытия возражений.

## Контрольные поля в трекере

- `status`: `payment_pending` -> `won`
- `next_step`: `payment_check` / `delivery_start`
- `next_step_at`: дата проверки оплаты
- `deal_value_rub`: сумма пакета
