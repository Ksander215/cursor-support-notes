# OpenCode Daily Revenue Routine

Цель: каждый день запускать повторяемый цикл, который повышает выручку, а не просто генерирует идеи.

## Morning block (20-30 min)

1. Открыть OpenCode в корне проекта.
2. Перейти в Plan mode.
3. Вставить промпт:

```text
Роль: Revenue sprint operator.
Контекст: sec-scanner.pro, legal-only mode, горизонт 14 дней.
Вход: вчерашние лиды и сделки (из OUTBOUND_72H_TRACKER.csv и Vibe Kanban).
Сформируй:
1) Топ-3 действия на сегодня с ожидаемым денежным эффектом.
2) 5 персонализированных outreach сообщений под лиды P0/P1.
3) Один CTA-пост для Telegram на сегодня.
4) Чеклист рисков, которые могут сорвать выручку сегодня.
Формат: коротко, по пунктам, без воды.
```

## Midday block (15 min)

- Build mode: доработать лучший оффер/сообщение по факту ответов.
- Перегенерировать только те куски, где просела конверсия.

Промпт:

```text
Обнови оффер на основе факта:
- какие сообщения не дали ответ
- какие ответы были возражениями
Дай 3 версии более сильного текста с разным углом:
1) срочность
2) снижение риска
3) экономия времени/денег
```

## Evening block (20 min)

Промпт:

```text
Сделай end-of-day revenue review.
Вход:
- новые лиды
- диалоги
- оплаты
- причины отказов
Выход:
1) Итог дня по KPI (факт vs план)
2) Что оставить завтра
3) Что остановить завтра
4) Один конкретный эксперимент на завтра (оффер/цена/канал)
```

## Handoff to Cursor/Vibe

- Сильные артефакты переносить в карточки Vibe Kanban.
- Итог дня фиксировать в `MAIN_AGENT.md` одной строкой.
- Если OpenCode генерирует крупный пакет изменений, сначала ревью в Cursor, потом запуск.
