# Hybrid Platform Stack (14 days)

Цель: быстрое получение оплат до ИП, без потери качества и с подготовкой перехода на сайт-оплату.

## 1) Стек площадок (фиксируем)

- `Telegram DM` — primary канал быстрых касаний и закрытия.
- `Telegram чаты` — secondary канал массового first-touch.
- `Kwork` — фриланс-биржа #1 (горячие заявки, фиксированные пакеты).
- `FL.ru` — фриланс-биржа #2 (B2B/срочные задачи).
- `Сайт` (`/audit`, `/course`, `/templates`) — обязательный оффер-хаб и price anchor.

## 2) Роли каналов

- `Telegram`: скорость ответа и догрев.
- `Биржи`: входящий поток лидов с дедлайнами.
- `Сайт`: доверие, структура оффера, единая цена.

## 3) Канонический путь сделки

`contacted -> qualified -> call/proposal -> payment_pending -> won/lost`

Для каждого лида обязателен `lead_source`.

## 4) SLA по каналам

- Telegram DM: ответ <= 15 минут (рабочее окно).
- Биржи: ответ <= 15 минут после нового отклика.
- КП после звонка: <= 30 минут.
- Follow-up D+1 и D+2 — без пропусков.

## 5) Daily channel split

- 50% касаний: Telegram DM.
- 30% касаний: биржи (отклики + outbound).
- 20% касаний: Telegram чаты + re-engage.

## 6) Exit criteria (14 дней)

- Минимум 2 активных источника лидов: Telegram + 1 биржа.
- 100% сделок с заполненными полями: `lead_source`, `status`, `next_step`, `deal_value_rub`.
- Сайт используется в каждом оффере как ссылка-подтверждение цены.
