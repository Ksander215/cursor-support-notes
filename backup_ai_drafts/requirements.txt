🤖 Запрос: Создай requirements.txt для FastAPI проекта
===========================
FastAPI использует Pipenv или Poetry для управления зависимостями, но если вы предпочитаете просто файл `requirements.txt`, вам потребуется добавить все необходимые библиотеки и версии.

Примерный вид `requirements.txt` может выглядеть так:

```plaintext
fastapi==0.63.1
uvicorn==0.14.0
sqlalchemy==1.4.25
python-multipart==0.0.8
passlib[bcrypt]==1.7.2
pyjwt==2.3.0
python-dotenv==0.19.2
```

Этот файл должен находиться в корневой директории вашего проекта и будет использован Pip, чтобы установить все зависимости:

```shell
pip install -r requirements.txt
```

Важно помнить, что `requirements.txt` не предназначен для управления версиями библиотек и он может содержать лишние зависимости, выбранные для вашего проекта.
