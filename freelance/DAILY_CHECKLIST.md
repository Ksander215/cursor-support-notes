# Ежедневный чек-лист фрилансера

## Утро (30 минут)

- [ ] Запустить утреннее напоминание: `python3 freelance/telegram_bot.py --morning`
- [ ] Открыть биржи: FL.ru, Kwork
- [ ] Проверить новые заказы (фильтр: Python, API, bot, automation, security)
- [ ] Откликнуться минимум на 5 заказов на FL.ru
- [ ] Откликнуться минимум на 3 заказа на Kwork
- [ ] Ответить на все сообщения клиентов
- [ ] Записать отклики в трекер: `python3 freelance/add_order.py`

## День (2-4 часа работы)

- [ ] Работать над текущими заказами
- [ ] Отправлять промежуточные результаты клиентам
- [ ] Обновлять статус в TRACKER_ORDERS.csv
- [ ] Делать перерывы каждые 50 минут (метод Pomodoro)

## Вечер (30 минут)

- [ ] Запустить вечерний отчёт: `python3 freelance/telegram_bot.py --evening`
- [ ] Проверить ответы на отклики
- [ ] Ответить на все новые сообщения
- [ ] Запланировать задачи на завтра
- [ ] Записать обновления в трекер: `python3 freelance/add_order.py`
- [ ] Посмотреть статистику: `python3 freelance/stats.py`

## Конец недели (1 час)

- [ ] Посчитать заработок за неделю
- [ ] Посчитать средний чек
- [ ] Посчитать конверсию:
  - Сколько откликов отправлено
  - Сколько ответов получено
  - Сколько заказов получено
- [ ] Планировать цены на следующую неделю
- [ ] Обновить портфолио (добавить новые кейсы)

## Формула расчёта конверсии

```
Конверсия откликов = (ответы / отклики) * 100%
Конверсия ответов = (заказы / ответы) * 100%
Общая конверсия = (заказы / отклики) * 100%
```

**Пример:**
- Откликов: 20
- Ответов: 8
- Заказов: 3

```
Конверсия откликов = (8 / 20) * 100% = 40%
Конверсия ответов = (3 / 8) * 100% = 37.5%
Общая конверсия = (3 / 20) * 100% = 15%
```

## Цели по конверсии

**Месяц 1 (обучение):**
- Откликов: 50-100
- Ответов: 20-40 (40%)
- Заказов: 2-5 (15-20% от откликов)

**Месяц 2 (опыт):**
- Откликов: 40-60
- Ответов: 20-30 (50%)
- Заказов: 5-8 (25-40% от ответов)

**Месяц 3 (масштабирование):**
- Откликов: 20-30 (качественные)
- Ответов: 12-18 (60%)
- Заказов: 8-12 (40-60% от ответов)
