## Кворк 3: Security Audit

**Название:** Аудит безопасности API

**Описание:**

Автоматический скан безопасности API.

Что проверю:
✅ OWASP Top 10 для API
✅ Аутентификация и авторизация (JWT, OAuth2)

✅ Rate limiting, CORS
✅ Шифрование, SSL/TLS

Что получите:
✅ PDF отчёт с уязвимостями
✅ Рекомендации по исправлению
✅ Консультация (30 мин)

Инструмент: https://api.sec-scanner.pro (собственная разработка)

Бонус: бесплатный скан 1 endpoint для демо.

Срок: 1-2 дня.
