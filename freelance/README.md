# Freelance Toolkit

Набор инструментов для работы на фриланс-биржах.

## Структура

```
freelance/
├── README.md                  # Эта инструкция
├── FREELANCE_PROFILE.md       # Профиль для бирж
├── FREELANCE_RESPONSES.md    # Шаблоны откликов
├── TRACKER_ORDERS.csv        # Трекер заказов
├── DAILY_CHECKLIST.md        # Чек-лист на каждый день
└── parser_birges.py          # Парсер бирж (требует доработки)
```

## Быстрый старт

### Неделя 1: Регистрация

**День 1-2: FL.ru**
1. Открой: https://www.fl.ru
2. Регистрация → Fill profile from `FREELANCE_PROFILE.md`
3. Загрузи аватар
4. Подтверди email и телефон

**День 3-4: Kwork**
1. Открой: https://kwork.ru
2. Регистрация → Заполни профиль
3. Создай 2 услуги:
   - "Разработка Telegram бота" (1500-3000₽)
   - "API интеграция" (3000-5000₽)
4. Загрузи скриншоты sec-scanner.pro в портфолио

**День 5-6: Freelancehunt**
1. Открой: https://freelancehunt.com
2. Регистрация → Заполни профиль
3. Подтверди телефон

**День 7: Первые отклики**
1. Открой все 3 биржи
2. Используй шаблоны из `FREELANCE_RESPONSES.md`
3. Откликнись на 5-10 заказов на каждой бирже
4. Сохрани данные в `TRACKER_ORDERS.csv`

---

### Неделя 2: Работа с заказами

**Ежедневно:**
1. Утром: открой `DAILY_CHECKLIST.md`, пройди по пунктам
2. День: работай над заказами
3. Вечер: обнови трекер, подготовься к следующему дню

**Трекер заказов (`TRACKER_ORDERS.csv`):**
```csv
date,platform,order_id,client_name,order_title,status,price_rub,response_date,start_date,deadline,completed_date,notes
2026-04-08,FL.ru,12345,Иван,Telegram бот,new,3000,,,,,отклик отправлен
```

**Статусы:**
- `new` - новый отклик
- `responded` - клиент ответил
- `in_progress` - работа начата
- `completed` - работа закончена
- `cancelled` - отменено

---

### Неделя 3: Бюджет (5000₽)

**Распределение:**
| Биржа | Что купить | Стоимость |
|-------|-----------|-----------|
| FL.ru | Выделение откликов | 1500-2000₽ |
| Kwork | Продвижение услуги | 500-1000₽ |
| Freelancehunt | Пакет откликов | 1000-1500₽ |

**Итого:** 3000-4500₽ из 5000₽

---

### Неделя 4: Масштабирование

**Когда будет 5+ отзывов:**
1. Подними цены на 30-50%
2. Добавь услугу "Аудит безопасности API" (5000-15000₽)
3. Используй sec-scanner.pro как демо

## Использование sec-scanner.pro как портфолио

### Вариант 1: Скриншоты

1. Открой: https://api.sec-scanner.pro
2. Сделай скриншоты:
   - Главная страница
   - Free scan страница
   - Dashboard (если есть демо-аккаунт)
3. Загрузи в портфолио на всех биржах

### Вариант 2: Видео-демо

1. Запиши скринкаст (5-10 минут):
   - Показ главной страницы
   - Демонстрация free scan
   - Обзор результатов
2. Выложи на YouTube
3. Добавь ссылку в портфолио на биржах

### Вариант 3: Бесплатный скан для клиента

1. Клиент присылает URL его API
2. Ты открываешь: https://api.sec-scanner.pro/free-scan
3. Вводишь email клиента и его URL
4. Клиент получает отчёт
5. Ты пишешь: "Это базовый скан. Полный аудит = 10000₽"

## Проблемы и решения

### Нет ответов на отклики

**Причины:**
- Слишком высокая цена
- Слишком длинный отклик
- Нет портфолио
- Отклик отправлен поздно

**Решения:**
- Снизь цену на 20-30%
- Сократи отклик до 3-4 предложений
- Добавь скриншоты sec-scanner.pro
- Откликайся в течение 30 минут

### Нет заказов

**Причины:**
- Мало откликов (< 10 в день)
- Нет портфолио
- Нет отзывов
- Высокая цена

**Решения:**
- Увеличь количество откликов до 15-20 в день
- Сделай видео-демо sec-scanner.pro
- Предложи тестовое задание бесплатно или за 50%
- Снизь цены на 30-50%

### Клиент исчезает

**Решения:**
- Пиши в Telegram (быстрее, чем на бирже)
- Предложи созвон (10-15 минут)
- Отправь промежуточный результат
- Дай гарантию (оплата после выполнения)
